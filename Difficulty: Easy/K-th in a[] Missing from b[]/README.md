<h2><a href="https://www.geeksforgeeks.org/problems/find-k-th-missing-element2556/1">K-th in a[] Missing from b[]</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);" bis_skin_checked="1"><p><span style="font-size: 14pt;">Given two integer arrays <strong>a[]</strong> and <strong>b[]</strong>, where a[] is sorted in strictly increasing order and b[] is an unsorted array, find the <strong>k-th</strong> element of a[] that is not present in b[]. If fewer than k such elements exist, return -1.</span></p>
<p><strong style="font-size: 14pt;">Examples:</strong></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> a[] = [0, 2, 4, 6, 8, 10, 12, 14, 15], b[] = [4, 10, 6, 8, 12], k = 3</span><br><span style="font-size: 14pt;"><strong>Output:</strong> 14</span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> The missing numbers from a[] that are not in b[] are [0, 2, 14, 15]. The 3rd missing number is 14.</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> a[] = [1, 2, 3, 4, 5], b[] = [5, 4, 3, 1, 2], k = 3</span><br><span style="font-size: 14pt;"><strong>Output:</strong> -1</span><br><span style="font-size: 14pt;"><strong>Explanation:</strong> All numbers from a[] are present in b[], so there is no missing element.</span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:<br></strong></span><span style="font-size: 14pt;">1 ≤ a.size(), b.size(), k ≤ 10<sup>5</sup><br></span><span style="font-size: 14pt;">0 ≤ a[i], b[i] ≤ 10<sup>5</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>STL</code>&nbsp;
