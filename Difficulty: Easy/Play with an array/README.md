<h2><a href="https://www.geeksforgeeks.org/problems/play-with-an-array/1">Play with an array</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);" bis_skin_checked="1"><p><span style="font-size: 14pt;">Given a 0-indexed array <strong>arr[] </strong>of positive integers, determine if it is possible to rearrange the array elements such that the number at the <strong>odd</strong> index is strictly greater than the number at the <strong>previous even</strong> index.<br>Formally, return <strong>true </strong>if the array can be rearranged such that <strong>arr[i] &gt; arr[i-1]</strong> for all valid <strong>odd </strong>indices. Otherwise, return <strong>false</strong>.</span></p>
<p><span style="font-size: 14pt;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [5, 4, 3, 2, 1]
<strong>Output:</strong> true
<strong>Explanation: </strong>Rearranging to [4, 5, 2, 3, 1]<strong style="font-size: 14pt;"> </strong>is valid because the elements at odd indices are strictly greater than the preceding even indices (5 &gt; 4 and 3 &gt; 2).</span></pre>
<pre><span style="font-size: 14pt;"><strong>Input:</strong> arr[] = [4, 1, 1, 1]
<strong>Output:</strong> false<br></span><strong><span style="font-size: 14pt; font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">Explanation: </span></strong><span style="font-size: 14pt;">No rearrangement exists that satisfies the given condition.</span></pre>
<p><span style="font-size: 14pt;"><strong>Constraints:</strong><br>1 ≤ arr.size() ≤ 10<sup>5</sup><br>1 ≤ arr[i] ≤ 10<sup>6</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;
