Output :</strong> 3<br><strong>Explanation:</strong> The smallest element in the array is 3. <br>Since k = 1, we only need the smallest element, so the answer is [3].</span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Hash</code>&nbsp;
