<h2><a href="https://www.geeksforgeeks.org/problems/minimum-steps-to-make-product-equal-to-one/1">Minimum Steps for Product One</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);" bis_skin_checked="1"><p><span style="font-size: 14pt;">Given an array <strong>arr[]</strong> containing <strong>n </strong>integers. In one step, any element of the array can be increased or decreased by 1. Find the minimum number of steps required to make the product of all array elements equal to 1.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [-2, 4, 0]
<strong>Output: </strong>5
<strong>Explanation: </strong></span><span style="font-size: 18px;">Change -2 to -1, 4 to 1, and 0 to -1. The total number of steps is 1 + 3 + 1 = 5.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [-1, 1, -1] 
<strong>Output : </strong>0</span>
<span style="font-size: 18px;"><strong>Explanation: </strong>The product is already 1, so no steps are required.</span>
