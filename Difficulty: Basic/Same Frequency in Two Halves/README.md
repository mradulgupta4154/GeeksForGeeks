<h2><a href="https://www.geeksforgeeks.org/problems/riyas-test1450/1">Same Frequency in Two Halves</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);" bis_skin_checked="1"><p><span style="font-size: 18px;">Given a string <strong>s</strong>, split it into two halves from the middle. If the length of s<strong> </strong>is odd, ignore the middle character before splitting.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "abcdbca"
<strong>Output:</strong> true
<strong>Explanation: </strong>The string has length 7 which is odd, hence we ignore the middle character 'd'. The frequency of 'a', 'b' and 'c' is same in both the halves.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>s = "abbaab"
<strong>Output:</strong> false
<strong>Explanation:</strong> The first half "abb" and the second half "aab" do not have the same character frequencies.</span></pre>
